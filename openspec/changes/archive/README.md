# SDD Change Archive

Completed SDD changes are stored here with date prefixes in the format `YYYY-MM-DD-{change-name}/`.

Each archived change contains:
- `proposal.md` - Original change proposal
- `spec.md` - Detailed specification
- `design.md` - Technical design decisions
- `tasks.md` - Implementation tasks (all checked items completed)
- `verify-report.md` - Verification results

These artifacts provide a complete audit trail of the change process.
